Windows: adapter driver

      
    
        
  1. Plug in the official Nintendo GameCube adapter (Wii U / Switch version, set to the Wii U position).
    2. 
        
  2. Download Zadig, choose Options → List All Devices, select WUP-028, pick WinUSB as the driver and click Replace/Install.
    3. 
        
  3. Click Connect GC adapter here and choose the adapter.
    4. 
      

      
This is the same driver Dolphin uses for the adapter, so if Dolphin already works with it nothing else is needed. Only one program can use the adapter at a time: close Dolphin first.

    

    

      
Linux: permissions

      
The .deb package installs a udev rule automatically. For the AppImage (or other installs) add the rule once:

      
sudo cp 51-gcadapter.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger

      
The rule file is in the app's resources folder (and in the source repo under build/linux). Then unplug and replug the adapter. Close Dolphin or any other program using the adapter first.

    

    

      
Troubleshooting

      
    
        
  • "No device selected" / nothing in the list: the adapter is not on the WinUSB driver (Windows) or lacks permissions (Linux), or the switch is not on the Wii U position.
    • 
        
  • Can't claim interface: another program (Dolphin, a driver tool) has it. Close it and replug.
    • 
        
  • Ports show "–": no controller detected on that port. Pick the right port; wireless controllers must be paired.
    • 
        
  • Sticks look dead on a Phob: press B once after plugging in to wake the sticks (see the 0.31 guide). Mayflash adapters need both USB connectors plugged in.
    • 
        
  • Low sample rate warning: only the adapter reports at about 125 Hz; browser-gamepad mode (about 60 Hz) is not suitable for snapback tests.
    • 
      

    

    

      
About the firmware profiles

      
The walkthroughs are driven by profile files, one per firmware version. 0.31 and 0.25 - 0.29 are transcribed from the official per-version guides (0.30 was never released; nothing below 0.25 is supported). Steps are marked unverified where the source did not say. You can import your own profile (Import button) to add or correct a version; use Export on an existing profile as a template.

      
Official sources: Calibration guide (latest) · PhobGCC-doc
